## Проект обучения

Данный репозиторий - мой проект обучения в университете.

Пройденные 1 и 2 курс за ненадобностью локально заархивированы, но полностью доступны в удалённом репозитории.

### Структура

Проект разбит на курсы.

Курсы внутри разбиты на семестры.

Внутри семестров вне предметы, которые учитываются для текущего семестра.

### Порядок работы с проектом

Необходимо выполнять задания, указанные пользователем.

Например:
```
Прочти файл `3 curs\1 semestr\Тестирование программного обеспечения\Lab1\Лабораторная работа 1`, выполни ёё в отдельном Java-проекте, создай его в той же конечно директории.
```

Соответственно, необходимо ознакомиться с документацией на задание и выполнить его как обозначил пользователь.

По мере выполнения или перед выполнением уточнять детал реалзации, если есть вопросы.

### Ограничения

- При написании кода только компилировать проект, не запускать и не тестировать, если явно не сказано пользователем;
- Без надобности и указания пользователя не покидать репозиторий в поисках чего-либо в системе;
- Запрашивать у пользователя разрешение на удаление файлов;
- Не выполнять `git commit`, `git push` без явного указания пользователя - в данном проекте это лишнее, файлы коммитятся особенно выборочно.

### Разрешения

- Компилировать написанный код: на данный момент в системе установлены jdk и php. По мере необходимости, пользователь сам установит необходимые внешние зависимости.
